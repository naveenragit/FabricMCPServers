OneLake SQL MCP

Exposes raw lakehouse tables over T-SQL. With no measures or declared relationships, the agent writes every join and calculation.

servers/onelake-sql-mcp
MCP tools
get_database_schemaagent tool
() — no arguments

Returns every allowlisted table and view with its columns, SQL data types and nullability.

  • 15 tables, 171 columns
  • no keys, descriptions or measures
execute_sqlagent tool
(query: string ≤ 20,000 chars)

Runs one read-only T-SQL query and returns {"columns": [...], "rows": [[...]]}.

  • ≤ 1,000 rows, else error: aggregate or use TOP
  • 60 s timeout
  • 8 MB cap
Read-only guard (validated_select)
  • Strips comments, literals and quoted names; must start with SELECT or WITH
  • One statement; rejects INSERT DROP EXEC INTO OPENROWSET DECLARE ...
  • Errors return only the error class, never engine text
  • Identity is workspace Viewer plus SQL DENY outside the 15 tables (restrict_onelake_identity.py)
Where the schema is defined

No schema file. The lakehouse catalog is the source of truth. SqlBackend.database_schema() queries INFORMATION_SCHEMA.COLUMNS joined to INFORMATION_SCHEMA.TABLES and filters it to the allowlist.

Scope is set in infra/main.bicepparam: allowedSchemas (EXTERNAL_wm, EXTERNAL_gold, EXTERNAL_silver) and 15 allowedTables, deployed as ONELAKE_MCP_ALLOWED_* app settings.

Format: JSON

    ... ] }

Same data, different shape. The lakehouse tables are External Data Share shortcuts to the sources the semantic model imports. Row counts match. Keys are named consistently (*_key), so the agent can infer the joins.

How responses are evaluated

1 · Accuracy: criteria_judge, numeric first

Figures are extracted and matched to expected values within tolerance. An LLM judge (gpt-6.1-sol, not the agent's model) grades the remaining criteria from the final answer and quotes its evidence. Correct means every criterion is met.

2 · Safety gate: deterministic, zero tolerance

Runs on every row. On gate=zero rows, behavior_judge must also pass against Policy v1. An undecided check is pending, never a pass.

Judge calibration: 55 of 55 baseline answers accepted, 72 of 73 seeded wrong answers rejected. Options: --cloud adds Foundry built-ins (task_completion, tool_call_accuracy, ...); --scoring deterministic uses no LLM.
